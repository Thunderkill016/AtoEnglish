# AtoEnglish 28-Day Speaking Journey — HISTORICAL CONTRACT

**Status:** historical curriculum/product hypothesis  
**Superseded as active contract:** 2026-09-06 project reset  
**Canonical current state:** `docs/project/PROJECT_STATE.md`

This file previously defined a 28-day, 10–15 minute/day workplace-speaking journey for Vietnamese adults, including a Day 1 boundary, prompt-support fading, checkpoints, and final speaking performance.

It is **not an active curriculum contract during the project reset**.

## Reusable findings

The historical work contains several potentially useful design constraints:

- one measurable speaking outcome per session;
- a short daily scope rather than one overloaded 40-minute container;
- model → retrieval → supported speaking → reduced prompts → changed situation;
- required spoken output;
- concise feedback followed by immediate retry;
- later retrieval of useful chunks;
- final performance without a full-script prompt.

It also recorded a concrete mismatch still present in the audited repository: landing copy promises 10–15 minutes/day while `unitA01.ts` declares a 40-minute first unit with substantially broader material.

That mismatch is an input to future product research. It does **not** automatically authorize a Day 1 rewrite or reinstate the 28-day pilot.

## Historical scope

The former journey targeted:

- greeting and name;
- spelling a Vietnamese name;
- role/workplace/responsibility;
- five predictable work questions;
- repair phrases;
- a 30–45 second work introduction;
- prompt support reducing from full models toward independent performance.

Exact day-by-day sequencing, support levels and acceptance criteria remain available in Git history and are summarized for reuse in `docs/project/ARCHIVE_INDEX.md`.

A future AtoEnglish curriculum direction must explicitly decide whether to reuse, modify or discard this contract after the reset.
