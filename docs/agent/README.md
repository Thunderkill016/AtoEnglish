# Agent ops docs

Queue & rules live at **repo root** (hard-coded in `scripts/agent-*.sh`):

| Root file | Role |
|-----------|------|
| `AGENTS.md` | Coding rules, architecture summary |
| `AGENT_BACKLOG.md` | ready / in_progress / done |
| `AGENT_ROADMAP.md` | feature pool (refill) |
| `AGENT_PLAN.md` | current session plan |
| `AGENT_AUTOPILOT.md` | daemon / product loop |
| `AGENT_REPORT.md` | last cycle report |

Do **not** move these without updating all scripts.
