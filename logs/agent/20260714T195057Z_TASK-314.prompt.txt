=== THAM CHIẾU TRUNG TÂM (thiết kế nội dung) ===
• British Council — ESA (Engage / Study / Activate): Engage: kích thích + warm-up. Study: ngôn ngữ mục tiêu (từ, mẫu câu, nghe). Activate: dùng tự do trong task giao tiếp.
• CELTA lesson stages: Lead-in → Presentation/Clarification → Controlled practice → Freer practice → Feedback. Không dạy grammar trước khi có ngữ cảnh.
• Cambridge CEFR: Mỗi bài = can-do descriptors đo được (A1…B2). learningOutcomes phải khớp band.
• Paul Nation — Four Strands: Input có nghĩa + Output có nghĩa + Language-focused + Fluency. Vocab pre-teach trước dialogue.
• Trung tâm VN (Apollo / ILA / BC Vietnam pattern): CLT: học để nói được trong tình huống (công sở, du lịch, phỏng vấn). So sánh L1 Việt↔Anh rõ ràng. B1+ gắn TOEIC/IELTS task.

=== MAP TỪNG BLOCK ===
[Engage/Lead-in] hook: Giống slide mở đầu lớp BC: 1 tình huống thật + câu hỏi gợi mở. culturalNote = điểm khác biệt VN↔bản ngữ (pragmatic).
[Engage/Lead-in / activate schemata] warmup: 3 mẫu câu ngắn — như warm-up oral trong lớp Apollo: nghe → nhắc lại. Ôn unit trước (SRS).
[Study/Clarification — lexis] vocab: Presentation lexis BC: IPA + collocation + ví dụ câu. BẮT BUỘC l1_interference_vn (lỗi VN) như correction trong lớp ILA.
[Study/Clarification — MF(P)] grammar: Inductive CELTA: Meaning từ dialogue → Form (rule ngắn) → Pronunciation/usage. CCQ = concept checking (4 đáp án). vnNote = error correction tiếng Việt.
[Study/Controlled practice] exercises_input: Gap-fill, matching, listen-and-choose — độ khó ~80% đúng. Distractor gần đúng như đề TOEIC Part 5.
[Study/Meaningful input] dialogues: Script CLT: hội thoại tự nhiên, có translation. Chỉ từ đã học (98% coverage). Giống listening script BC Skills for Life.
[Activate/Fluency drill] fluency: Nation strand 4 + drill nói nhanh như fluency activity cuối Study. Câu ngắn, lặp 5+ lần.
[Activate/Freer practice + task] output: Task-based: dịch VN→EN (controlled production) → shadowing (pronunciation) → speaking level2 (role-play / situational). Bắt buộc SẢN XUẤT lời nói.
[Review/Feedback + consolidation] review: Exit quiz + cumulative review (spiral curriculum như giáo trình trung tâm 12–24 tuần). readingPassage = skills integration B1+.
[Engage/Aims on board] meta: description = 1 câu lợi ích (giống 'By the end of this lesson you will…'). XP/badge = động lực gamification, không thay can-do.
